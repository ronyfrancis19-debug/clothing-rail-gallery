# Clothing Rail Gallery

Interactive Product Rail Gallery component (fashion store hero section) built with React, Tailwind CSS, and TypeScript.

This is a faithful recreation of the [Product Rail Gallery](https://21st.dev/@dhxwhy/components/product-rail-gallery) from 21st.dev.

## Features
- Physics-based clothing rail with swinging hangers
- 3D front/back turning
- Detail modal with front/back flip
- Built-in SVG garment illustrations + support for product photos
- Autoplay, carousel on mobile, full keyboard & touch support
- Light/dark mode, prefers-reduced-motion

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy
- **Vercel**: Import this repo → deploy
- **Replit**: Import from GitHub
